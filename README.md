# 🏋️ FitLog

## 📌 Project Description

FitLog is a modern and responsive workout tracking web application that helps users explore workouts, view workout details, create a personal workout plan, and save their favorite exercises.

### Live Demo: https://fit-log-here.vercel.app/

## 🛠️ Technologies Used

* Next.js
* React
* TypeScript
* Tailwind CSS
* React Icons
* React Toastify


## 📌 Key Features

* Browse and explore workout library
* View detailed workout information
* Add workouts to personal workout plan
* Save for Later workouts
* Mark workouts as completed
